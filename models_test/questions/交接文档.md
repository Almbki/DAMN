## 1. 模型边界

第一层只输出：

- 5 个 domain 的 `theta`
- 每个 domain 的 `se`
- 每个 domain 的 95% `ci95`
- 每个 domain 的 `items_answered`
- 总题数与 `completed`

第一层**不输出**：

- MBTI
- high / medium / low 标签
- LLM 人格描述
- 调度建议
- task completion probability
- 30 facet theta

第二层应该把 Trait Model V1 当作只读输入，不要重新估计 theta，也不要修改 GRM/CAT 参数。

## 5. 核心 API

`cat.py` 与 UI/CLI 解耦，最小接口：

```python
import cat

session = cat.start_assessment()

item_id = cat.get_next_item(session)          # None 表示全部完成
# item_id 形如 "IPIP_016"

cat.submit_response(session, item_id, 1)      # response 必须为 1..5

profile = cat.get_trait_profile(session)
```

辅助接口：

```python
cat.mark_item_unavailable(session, item_id)    # 缺失/不可用题目
cat.load_grm_parameters()                       # 读取 GRM 参数
cat.category_probabilities(theta, a, thresholds)
cat.item_information(theta, a, thresholds)
```

### 调度

- domain 顺序：`N -> E -> O -> A -> C -> N -> ...`
- 已停止 domain 自动跳过
- 每个 domain 独立 posterior，互不影响

### 停止规则

```text
if items_answered >= 4 and se <= 0.35: stop
if items_answered >= 12: stop
```

参数来自 `artifacts/cat_config.json`，不要散落 hardcode。

UI 用 `questions.json[item_id]["text"]` 显示中文题干。`cat.py` 只返回 `item_id`，不负责文本。

### `artifacts/grm_parameters.json`

```json
{
  "model": "GRM",
  "version": "grm_v1",
  "domains": {
    "N": {
```

## 8. 冻结的验证指标

官方 619,150 respondents，seed `20261020`：

| Domain | Pearson r | MAE | RMSE | Mean items | Stop by SE |
|---|---:|---:|---:|---:|---:|
| N | 0.971 | 0.185 | 0.234 | 8.58 | 88.0% |
| E | 0.960 | 0.213 | 0.270 | 8.33 | 87.0% |
| O | 0.970 | 0.174 | 0.226 | 12.00 | 0.3% |
| A | 0.965 | 0.195 | 0.250 | 11.96 | 10.6% |
| C | 0.956 | 0.225 | 0.287 | 10.80 | 65.9% |

```text
Overall MAE: 0.198
Overall RMSE: 0.253
Average items/domain: 10.33
Overall stop-by-SE rate: 50.36%
Extreme-theta warning: None
```

已知限制：

- O/A 经常触发 `max_items=12`，最终 SE 约 0.40–0.41。
- 第二层应把 `se` 当作不确定度，不要假设五个 domain 的 theta 精度相同。
- 目标 SE 0.35 是比赛版 trade-off；不要为了追求更低 MAE 重调 GRM。

## 9. 新文件夹启动检查

在新文件夹中：

```powershell
python -c "import cat; s=cat.start_assessment(); print(len(s.states), s.config.target_se)"
```

应输出：

```text
5 0.35
```

如果用的是没有 scipy 的 Python，也没关系：`cat.py` 现在只需要 numpy。

### 快速自测

```python
import numpy as np
import cat

params = cat.load_grm_parameters()
true_theta = {"N": 0.8, "E": -0.4, "O": 1.1, "A": 0.2, "C": -0.9}
rng = np.random.default_rng(42)
s = cat.start_assessment()

while True:
    item = cat.get_next_item(s)
    if item is None:
        break
    d = s.last_domain
    b = params["domains"][d]["items"][item]
    p = cat.category_probabilities(np.array([true_theta[d]]), b["a"], b["thresholds"])[0]
    cat.submit_response(s, item, int(rng.choice(5, p=p) + 1))

print(cat.get_trait_profile(s))
```

### 交互式自测

```python
import json
import cat

bank = {q["item_id"]: q for q in json.load(open("questions.json", encoding="utf-8"))}
s = cat.start_assessment()

while True:
    item = cat.get_next_item(s)
    if item is None:
        break
    print(f"[{s.last_domain}] {bank[item]['text']}")
    while True:
        try:
            r = int(input("1-5: "))
            if 1 <= r <= 5:
                break
        except ValueError:
            pass
    cat.submit_response(s, item, r)

print(json.dumps(cat.get_trait_profile(s), ensure_ascii=False, indent=2))
```

## 10. 第二层接入建议

第二层读取：

```python
profile = cat.get_trait_profile(session)
for domain in "NEOAC":
    theta = profile["domains"][domain]["theta"]
    se = profile["domains"][domain]["se"]
    ci95 = profile["domains"][domain]["ci95"]
    n_items = profile["domains"][domain]["items_answered"]
```

建议第二层输入至少包含：

- 5 个 `theta`
- 5 个 `se`（或精度 `1/se`）
- `total_items_answered`
- `completed`

如果第二层需要逐题 response：

```python
session.states["N"].responses        # {item_id: 1..5}
session.states["N"].administered     # [item_id, ...]
session.states["N"].stopped          # bool
session.states["N"].stop_reason      # "target_se" / "max_items" / "no_available_items"
```

注意：`get_trait_profile()` 为了保持精简，不包含 `stopped` / `stop_reason`；需要时直接读 `session.states[d]`。

### 会话持久化

当前 `CATSession` 是内存对象，没有内置 JSON 序列化。若第二层是 stateless API：

- 保存 `responses`（item_id → 1..5）即可
- 重新 `start_assessment()` 后按保存顺序 replay `submit_response`
- 由于算法确定性，replay 会得到相同 posterior 和 profile
