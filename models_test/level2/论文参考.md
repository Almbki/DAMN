## ① 最重要：Bellhäuser et al., 2023

**Daily automated feedback enhances self-regulated learning: a longitudinal randomized field experiment**

这是你第二层最应该作为“主参考”的论文。

194 名大学生，连续 **36 天** electronic learning diary。研究本身每天就记录：

- planning
- self-efficacy
- motivation
- satisfaction
- adherence to time schedule
- procrastination
- effort

而且根据 daily data 自动反馈。[Frontiers](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2023.1125873/full?utm_source=chatgpt.com)

[免费下载全文（PMC）](https://pmc.ncbi.nlm.nih.gov/articles/PMC10233063/?utm_source=chatgpt.com)

你尤其应该让 Agent 阅读论文的：

因为里面直接告诉你他们 daily model 收了哪些变量、什么时候收、怎么反馈。

# 三、第二篇：Grunschel / Wäschle 等，2014

**Procrastination and self-efficacy: Tracing vicious and virtuous circles in self-regulated learning**

这篇对你的**状态更新逻辑**特别重要。

150 名大学生，持续 **19 周** self-monitoring。

研究三个核心变量：

\[ SelfEfficacy \]\[ Procrastination \]\[ PerceivedGoalAchievement \]

而且发现了 reciprocal feedback：

\[ GoalAchievement \leftrightarrow SelfEfficacy \]

以及：

\[ GoalAchievement \leftrightarrow Procrastination \]

Self-efficacy 还中介了之前 goal achievement 对 procrastination 的影响。[DOI](https://doi.org/10.1016/j.learninstruc.2013.09.005?utm_source=chatgpt.com)

[论文页面 / DOI](https://doi.org/10.1016/j.learninstruc.2013.09.005?utm_source=chatgpt.com)

这篇论文直接支持你说的：

> **今天反馈 → 学习 → 预测/更新明天状态。**

所以 `self_efficacy` 我认为应该留下。

# 五、第四篇：Åkerstedt et al., 2014

**Do sleep, stress, and illness explain daily variations in fatigue? A prospective study**

50 人连续 **42 天**：

- daily diary
- actigraphy

研究：

\[ Fatigue_d \]

和：

\[ Sleep_{d-1} \]\[ Stress_d \]

之间的日级关系。

结果支持日间 fatigue 与前一晚 sleep quality / duration，以及当天 stress 等存在 longitudinal association。[PubMed](https://pubmed.ncbi.nlm.nih.gov/24630177/?utm_source=chatgpt.com)

[PubMed 论文入口](https://pubmed.ncbi.nlm.nih.gov/24630177/?utm_source=chatgpt.com)

这篇主要支撑：

> **Fatigue 是合理的 daily state，而且昨天/今天的信息可以用于预测下一状态。**

所以以后如果接手机/手环 sleep data，有理论接口。

但 **V1 不需要实现睡眠数据。**

# 六、第五篇：Procrastination ambulatory assessment

**Fostering self-regulation to overcome academic procrastination using interactive ambulatory assessment**

89 名学生随机进入 intervention/control，使用 smartphone electronic diaries；干预组根据学习行为和拖延原因获得自动、个体化反馈。研究发现 intervention group 的 procrastination 下降、completed workload 增加，而且后续阶段效果仍然存在。[ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S1041608019300962?utm_source=chatgpt.com)

[论文页面](https://www.sciencedirect.com/science/article/abs/pii/S1041608019300962?utm_source=chatgpt.com)
