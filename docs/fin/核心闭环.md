## 核心闭环（三个环节）

```
环节 1 · 基础画像
  用户基础信息 ──►「MBTI 刻板印象」+「大众平均值」──► 基础画像
                                                      │
                                                      ▼
                                              画像评估用户状态
                                                      │
                                                      │ 画像（JSON 字段）
                                                      ▼
环节 2 · 目标 → 拆解（用户手动触发）
  用户创建目标 ──► 手动触发拆解 ──► LangGraph 拼三段提示词
                                    ① 基础提示词
                                    ② 画像提示词（画像模块生成的 JSON 字段）
                                    ③ 用户提示词（拆解时用户手动输入）
                                  ──► 生成任务清单
                                                      │
                                                      ▼
环节 3 · 执行 → 反馈 → 重排
  用户执行 Todo ──► LLM 生成反馈选择题及对应系数 ──► 用户产生反馈
                                                      │
                                                      ▼
                                              更新用户画像 ──► 画像预测任务完成概率
                                                      │
                                          完成概率过低 ──► 触发重排 ──► 新任务清单回到执行
                                                      │
                                                      └──► 新画像回流至环节 1 的状态评估
                                                          与环节 2 的画像提示词
```

### 环节 1：用户基础信息 → 基础画像 → 画像评估用户状态

用户基础信息（MBTI 类型等）经「MBTI 刻板印象」与「大众平均值」初始化为基础画像；画像负责评估用户状态，并向环节 2、环节 3 输出画像字段（JSON）。

### 环节 2：用户创建目标 → 手动触发拆解 → 生成任务清单

用户创建目标后**手动触发**目标拆解；LangGraph 依据三段提示词生成任务清单：

| # | 提示词 | 来源 |
| --- | --- | --- |
| ① | 基础提示词 | 系统内置 |
| ② | 画像提示词 | 画像模块生成的 JSON 字段 |
| ③ | 用户提示词 | 拆解时用户手动输入 |

### 环节 3：执行 Todo → 反馈 → 更新画像 → 预测完成概率 → 过低触发重排

用户执行 Todo；由 **LLM 生成反馈选择题及对应系数**，用户产生反馈后据此**更新用户画像**；画像**预测任务完成概率**，概率**过低即触发重排**。重排结果回到执行环节，新画像同时回流至环节 1 与环节 2，闭环闭合。
