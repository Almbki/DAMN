## 三、逐篇要点整理

### 1. Schmidt 等 (2007) — 昼夜节律与人类认知：经典综述（Cognitive Neuropsychology）

- **研究问题**：时间-of-day 波动如何影响注意、执行功能与记忆？节律型（chronotype）如何调节？
- **核心理论**：双过程模型雏形（睡眠压力 × 昼夜节律相位）；**同步效应（synchrony effect）**——当任务时间与个体昼夜唤醒峰值一致时表现最优。
- **IV**：昼夜相位、睡眠压力、chronotype、测试时刻。
- **DV**：注意、执行功能、记忆任务表现。
- **主要结论**：时间-of-day 影响广泛认知任务（注意、执行、记忆）；个体差异（chronotype）决定"峰值时段"；测试时刻与个体峰值的同步性是关键调节变量。
- **证据强度**：高（被引 440 的经典权威综述）。
- **研究局限**：2007 年，部分证据待更新；主要针对健康成人。
- **与本项目的关系**：为"个人最佳任务时间"概念奠基——任务时刻×用户节律的同步效应是排程优化的第一原理。
- **支持的系统设计**：Scheduler 加入"最佳时段匹配"维度；User State 维护用户峰值时段估计。
- **可采集数据**：任务执行时刻、任务表现序列、入睡/起床时间。
- **可形成的 User State**：`circadian_peak_window`（估计的认知峰值窗口）。
- **可成为哪一部分**：Statistical Model——时间×表现曲线的先验形状（双峰/单峰）；Rule——排程时段偏好。
- **推荐优先级**：★ 最高。整条证据链的奠基文献。

### 2. Goldin 等 (2020) — 节律型×学校时间交互预测学业表现（Nature Human Behaviour，随机分班）

- **研究问题**：chronotype 与上学时间的匹配度如何影响学业表现？
- **核心理论**：**节律-学校时间错配假说**——内部节律与外部时间（社会钟）错配损害学习。
- **IV**：chronotype（MSFsc）、学校时段（07:45 / 12:40 / 17:20 随机分配，N=753 阿根廷中学生）。
- **DV**：各科成绩（含数学）。
- **主要结论**：(1) 上午班中早型学生全科优于晚型（数学差异最大）；(2) 下午班该差异消失；(3) 晚型学生从晚间班获益。**成绩在校时与生物节律更对齐时提升**。
- **证据强度**：高（准实验随机分班，Nature Human Behaviour，被引 72）。
- **研究局限**：单一国家样本；随机分班仍受选课等约束。
- **与本项目的关系**：**最强证据**——把同一批任务安排在不同时段，因用户节律不同表现可反转；历史行为可以用于推断个人最佳任务时段。
- **支持的系统设计**：Scheduler 核心逻辑——按用户 chronotype 估计分配"高峰时段做高难度任务"；为晚型用户把困难任务移出清晨。
- **可采集数据**：各时段的任务完成表现、任务开始时刻、睡眠中点（可问卷或推断）。
- **可形成的 User State**：`chronotype`、`task_time_synchrony`（任务时间与节律的匹配度）。
- **可成为哪一部分**：Statistical Model——chronotype×时刻交互预测表现的模型蓝本；Rule——"清晨不为晚型排高认知任务"。
- **推荐优先级**：★ 最高。随机化设计的顶刊证据。

### 3. Tonetti, Natale & Randler (2015) — 昼夜偏好与学业成就：元分析（Chronobiology International）

- **研究问题**：晚型偏好（eveningness）是否整体上伴随更差学业表现？
- **核心理论**：昼夜偏好（circadian preference）→ 学业成就的相关结构。
- **IV**：circadian preference（MEQ/CSM 等量表）；DV：学业成就（27 309 人，31 项研究）。
- **主要结论**：晚型与更差学业表现相关，总体效应量 r≈0.14（小但显著）；中小学生（0.166）强于大学生（0.121）；自报成绩的效应（0.171）强于客观成绩（0.093）。
- **证据强度**：高（元分析，被引 82）。
- **研究局限**：多数研究横断面；效应量小；自报成绩偏差。
- **与本项目的关系**：给出"chronotype→学业表现"的基准效应量，供系统评估自身增益时对比；小效应提示 chronotype 只是诸多因素之一。
- **支持的系统设计**：chronotype 作为 User State 特征之一（非唯一）；用于时段偏好而非硬性评分。
- **可采集数据**：量表得分、成绩/完成率。
- **可形成的 User State**：`eveningness_score`。
- **可成为哪一部分**：Statistical Model——chronotype 系数先验（≈0.1-0.17）；Rule——不因晚型而预设能力低。
- **推荐优先级**：★ 高。效应量的量化基准。

### 4. van der Vinne 等 (2015) — 考试时刻对早/晚型成绩的不同影响（Journal of Biological Rhythms）

- **研究问题**：考试时刻与 chronotype 交互如何影响成绩？
- **核心理论**：同步效应 + 社会时差（social jetlag）的考试场景验证。
- **IV**：chronotype（MCTQ，MSFsc）、考试时刻（早 08:15-09:45 / 晚 10:00-12:15 / 下午 12:45-15:00）。
- **DV**：4734 份成绩（741 名荷兰中学生）。
- **主要结论**：非常晚型（MSFsc>5.31h）或工作日睡眠过短者成绩最低；**早型在上午考试显著优于晚型，该差异在下午消失**；同一内部时间下晚型仍更差（反映整体学习劣势）。
- **证据强度**：高（大样本自然数据，被引 64）。
- **研究局限**：观察性；成绩非标准化测试。
- **与本项目的关系**：直接支持"把测试/关键任务安排在下午可减少晚型歧视"以及"个人最佳考试时段"概念。
- **支持的系统设计**：关键任务（测验、报告）排程建议窗口（如下午 12:45 后对晚型更友好）。
- **可采集数据**：任务完成时刻、完成质量、用户睡眠中点估计。
- **可形成的 User State**：`peak_performance_window`。
- **可成为哪一部分**：Rule——"高重要性任务避开用户低谷时段"；Statistical Model——成绩×时刻×chronotype 交互回归。
- **推荐优先级**：★ 高。任务时刻影响成绩的直接证据。

### 5. Haraszti 等 (2014) — 社会时差负向预测大学生学业表现（Chronobiology International）

- **研究问题**：社会时差（SJL）与学业表现的关系？自由日睡眠时刻如何调节？
- **核心理论**：社会时差 = 工作日/自由日睡眠中点差；错配损害节律稳定性。
- **IV**：SJL（MCTQ 计算）、自由日睡眠中点、每周测试时刻（N=753，匈牙利）。
- **DV**：周测平均成绩与期末成绩（N=247）。
- **主要结论**：SJL 显著负向预测周测成绩（p=0.028），但在无强制日程的考试期消失；自由日睡眠晚的学生上午测试成绩差、下午反而更好。
- **证据强度**：中高（被引 128，大样本）。
- **研究局限**：单校样本；SJL 与成绩因果关系不完全。
- **与本项目的关系**：SJL 是**可从作息日志直接计算的连续型用户特征**，且随周内日程变化——比单一量表更动态。
- **支持的系统设计**：User State 持续更新 SJL；Scheduler 在工作日高峰/低谷建模中融入 SJL 修正。
- **可采集数据**：入睡/起床时间（自报或设备）、工作日/周末差异、任务时段表现。
- **可形成的 User State**：`social_jetlag`、`free_day_phase`。
- **可成为哪一部分**：Statistical Model——SJL 作为连续预测特征；Rule——SJL 高者上午任务风险提示。
- **推荐优先级**：★ 高。可观测可计算的核心节律特征。

### 6. Beşoluk, Önder & Deveci (2011) — 早晚偏好与大学生学业成就（Chronobiology International）

- **研究问题**：昼夜偏好是否预测学业成就？上课时段与考试时刻的作用？
- **核心理论**：MEQ 评分 → 学业成就 + 教学时段匹配。
- **IV**：MEQ 得分、教学时段（08:00-14:50 vs 15:00-21:50）；DV：CGPA、09:30 期末考成绩（N=1471）。
- **主要结论**：MEQ 部分预测学业成功；教学时段影响成绩；**09:30 早考中早型显著优于晚型与中间型**。
- **证据强度**：中高（大样本横断面，被引 86）。
- **研究局限**：横断面；成绩与课程难度未完全控制。
- **与本项目的关系**：再次验证"早间考试偏袒早型"；教学时段（上午/下午班）本身改变学生群体构成。
- **支持的系统设计**：用户任务时段偏好画像（morning/evening/intermediate 三档）。
- **可采集数据**：量表（MEQ 简版）、任务表现按时刻聚合。
- **可形成的 User State**：`chronotype_tier`（早/中/晚三档）。
- **可成为哪一部分**：Statistical Model——分档作为类别特征；Rule——档位×时段排程矩阵。
- **推荐优先级**：中高。经典三档分类法。

### 7. Onyper 等 (2012) — 上课开始时间、睡眠与学业表现：路径分析（Chronobiology International）

- **研究问题**：大学上课开始时间通过什么路径影响学业表现？
- **核心理论**：路径分析——晚课→更多睡眠/更少困意，但也→饮酒与逃课风险。
- **IV**：上课开始时间、chronotype、睡眠、饮酒等。
- **DV**：学业成绩（路径模型）。
- **主要结论**：晚课学生睡得更长、困意更少、逃课更少；但**成绩反而略低**（酒精滥用中介）；早晨偏好者全天功能更好。后期课程对成绩无益。
- **证据强度**：中高（路径分析，被引 53）。
- **研究局限**：单校；因果依赖模型假设。
- **与本项目的关系**：警示"排到下午/晚上 ≠ 自动更好"——时段影响是多路径的（睡眠、酒精、纪律），系统应基于个体实测而非群体平均。
- **支持的系统设计**：个人化的时段-表现曲线优先于群体模板；结合睡眠/作息特征。
- **可采集数据**：上课/任务开始时间、睡眠时长、表现。
- **可形成的 User State**：`time_window_profile`（个体实测曲线）。
- **可成为哪一部分**：Statistical Model——个体化时段效应估计（随机效应模型）。
- **推荐优先级**：中高。提醒避免群体平均假设。

### 8. Cohen-Zion & Shiloh (2018) — 晚型与困意预测执行功能与学业受损（Chronobiology International）

- **研究问题**：睡眠因素（困意、时段偏好）如何解释青少年日常执行功能与成绩？

- **证据强度**：高（超大样本 SEM，被引 9）。
- **研究局限**：横断面；自报生产力。
- **与本项目的关系**：**成人工作场景的直接证据**——时段错配通过睡眠紊乱降低工作生产力；与"完成效率/完成时间"直接相关。
- **支持的系统设计**：Duration Predictor 用睡眠/节律特征修正；工作时段排程尊重用户睡眠中点。
- **可采集数据**：睡眠时间、任务完成时间/质量、生产力评分。
- **可形成的 User State**：`presenteeism_risk`、`sleep_disturbance`。
- **可成为哪一部分**：Statistical Model——节律→效率的结构方程先验；Rule——晚型不安排早高峰任务。
- **推荐优先级**：★ 高。成人工作场景的量化证据。

### 21. Munnilari 等 (2024) — 认知表现相关变量的昼夜变化：系统综述（Sleep and Breathing）

- **研究问题**：健康成年男性中，认知功能随时刻如何变化？
- **核心理论**：昼夜变化幅度高度依赖任务类型。
- **IV**：时刻（早/晚两时点起）；DV：反应时、警觉、注意等认知指标（11 项研究）。
- **主要结论**：认知表现随时刻变化，幅度高度任务依赖——反应时差异 9.0-34.2%、警觉 7.3%、注意 7.8-40.3%；**反应时与准确率在傍晚最高**；无研究满足全部时间生物学方法学标准。
- **证据强度**：中高（系统综述，被引 20）。
- **研究局限**：仅 11 项合格；方法学异质；结果矛盾。
- **与本项目的关系**：给出时段效应的**幅度范围**（任务依赖），供 Duration Predictor 的时段修正系数取值；也提醒方法学陷阱（需同一人多时点测量）。
- **支持的系统设计**：时段修正系数按任务类型分档（注意类最大 40%）。
- **可采集数据**：任务类型×时刻×表现（个体内设计）。
- **可形成的 User State**：`time_of_day_adjustment`（任务依赖）。
- **可成为哪一部分**：Statistical Model——时刻效应幅度先验（9%-40%）；Rule——注意密集型任务的时段权重。
- **推荐优先级**：中高。效应量幅度的汇总来源。

### 22. Chauhan 等 (2025) — 节律型与同步效应的最新系统综述（Chronobiology International，PRISMA）

- **研究问题**：chronotype 单独及其×时刻交互对认知功能的影响？年龄的作用？
- **核心理论**：同步效应的边界条件（年龄、任务、唤醒因素）。
- **IV**：chronotype、最优/次优时刻、年龄组（18-45 / 50-95）。
- **DV**：注意、抑制、记忆等（65 项研究）。
- **主要结论**：>80% 研究未发现 chronotype 主效应；29/64（45%）成人研究在注意/抑制/记忆上发现同步效应；**老年人 10/12（83%）研究显示同步效应**（尤其流体能力任务）——同步效应在老年人中更强更一致。
- **证据强度**：高（2025 年最新 PRISMA 系统综述，被引 4）。
- **研究局限**：异质性大；发表偏倚未校正。
- **与本项目的关系**：**年龄调节同步效应**——年长用户（若系统面向成人/在职者）的时段匹配权重应更高；chronotype 主效应弱，交互效应为主。
- **支持的系统设计**：年龄分层模型；时段匹配权重随年龄上调。
- **可采集数据**：年龄、chronotype、时刻、表现。
- **可形成的 User State**：`synchrony_sensitivity`（随年龄）。
- **可成为哪一部分**：Statistical Model——年龄×同步性交互；Rule——老年用户严格避峰排程。
- **推荐优先级**：★ 高。最新综述，边界条件清晰。

### 23. Hawks 等 (2023) — 用密集纵向数据精确预测瞬时认知（Biological Psychiatry CNNI）

- **研究问题**：远程、自然环境下，哪些因素预测瞬时认知表现（momentary cognition）？
- **核心理论**：高强度纵向设计 + 数据驱动高维特征排序。
- **IV**：年龄、人际平均表现、**时间-of-day**、自报环境（噪声）与内部（压力）状态等。
- **DV**：瞬时反应时与准确率（N=122，平均 25.5 次/人评估）。
- **主要结论**：**反应时可预测性 R²>0.70，准确率 R²=0.35-0.56**；最强预测 = 年龄 + 人内平均 + **时间-of-day**；环境/内部状态也有贡献。
- **证据强度**：高（高强度纵向 + 样本外验证，被引 16）。
- **研究局限**：样本偏年轻女性；认知测试特定。
- **与本项目的关系**：**方法学模板**——时刻是瞬时认知最强的预测之一，说明"当前时段"必须在 Duration Predictor/User State 中占位。
- **支持的系统设计**：Duration Predictor 纳入 hour-of-day 特征；用户表现模型用混合效应（人内/人间）。
- **可采集数据**：任务时刻、RT、准确率、环境/压力自评（EMA）。
- **可形成的 User State**：`momentary_cognition_prediction`（含时刻项）。
- **可成为哪一部分**：Statistical Model——高维特征排序方法借鉴；ML——GAM/混合模型预测瞬时表现。
- **推荐优先级**：★ 高。直接的方法与结论参考。

### 24. Hernandez 等 (2023) — EMA 问卷反应时作为认知速度指标（JMIR mHealth and uHealth）

- **研究问题**：非认知 EMA 问卷的答题反应时能否作为认知处理速度的代理指标？
- **核心理论**：被动采集行为副产物（RT）估计认知状态。
- **IV**：EMA 问卷条目反应时（情绪等非认知条目）、时刻、疲劳。
- **DV**：Symbol Search 处理速度、Go-No Go 持续注意（2 周 EMA，5-6 次/天，1 型糖尿病患者）。
- **主要结论**：**单条目 EMA RT 即可作为平均处理速度的可靠代理**（BP 相关 0.43-0.58，p<0.001）；WP 层面与 Symbol Search 相关 0.29-0.58；与瞬时疲劳与时刻呈理论预期关系；与注意任务区分良好（发散效度）。
- **证据强度**：中高（密集纵向验证，被引 15）。
- **研究局限**：特定临床人群；EMA 条目少。
- **与本项目的关系**：**零成本认知信号**——用户每天多次轻量状态问卷（"你现在感觉如何"）的答题反应时本身就是认知速度估计，无需额外测试。
- **支持的系统设计**：ESM 模块采集状态自评的同时记录答题 RT，自动进入 User State 估计。
- **可采集数据**：问卷条目 RT、疲劳/情绪自评、时刻。
- **可形成的 User State**：`ema_rt_cognition_proxy`、`momentary_fatigue`。
- **可成为哪一部分**：Statistical Model——RT 代理的标定与融合；ML——弱标签（EMA RT）训练认知模型。
- **推荐优先级**：★ 高。完全贴合"轻量自评 + 行为副产物"的系统约束。

## 四、方向小结（对本项目的综合启示）

1. **时间段确实影响认知表现，且幅度可观**：反应时差异可达 9-34%、注意 8-40%（[21]）；个体内反应时可预测性 R²>0.70 中时刻是核心特征（[23]）。Scheduler 与 Duration Predictor 必须纳入"任务时刻"。
2. **同步效应是核心机制**：任务时刻×用户节律峰值的匹配决定表现（[1][2][18][22]）；随机化设计证实"时段对齐改善成绩、错配可反转表现"（[2]）；老年用户同步效应更强（[22]）。
3. **不同任务类型适合不同时段**：流体认知任务（数学/科学/新知识学习）对时刻敏感，晶体任务（复习/阅读）不敏感（[13]）；注意/抑制/记忆类任务同步效应最稳（[18][22]）。
4. **个体差异可观测**：chronotype（MEQ/CSM）、睡眠中点（MSFsc）、社会时差（SJL）都可由问卷与作息日志计算（[3][5][12]）；困意与节律相位比睡眠时长更预测日常执行（[8][14]）；历史行为数据可直接推断个人最佳任务时间（[2][23][24]）。
5. **跨日闭环**：晚型→就寝拖延→睡眠不足→日间疲劳/低自控→次日表现差的循环（[15][16][20]）；系统可在"晚间收尾""就寝提醒"节点干预，并在次日用节律特征解释表现方差。
6. **落地约束**：chronotype 主效应弱（meta 效应量 r≈0.14，[3]）、须个体化实测而非群体平均（[7][11]）；方法学上应做个体内多时点测量（[21]），并把时刻作为评估 A/B 效果时的协变量（[18]）。
