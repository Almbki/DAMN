2. 若属于"本目录自造概念"（如证据标记制度），放入 A 类；
3. 同一术语不要重复登记；若发现既有解释有误，**保留原行并在其后追加"（修正见下）"说明**，不要直接删改历史。
4. 新增后在本表头部"更新日期"处更新日期。
