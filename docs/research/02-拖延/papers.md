## 三、逐篇要点整理

### 1. Steel (2007) — 拖延的本质：元分析与理论综述

- **研究问题**：拖延的原因与后果中哪些是稳定且一致的预测因素？拖延理论综合。
- **核心理论**：时间动机理论（TMT）= 期望理论 × 双曲贴现；拖延是自我调节失败（quintessential self-regulatory failure）。
- **自变量（IV）**：任务厌恶、任务延迟（deadline 距离）、自我效能、冲动性、尽责性及其子维度（自控、易分心、组织性、成就动机）、神经质、叛逆、感觉寻求等。
- **因变量（DV）**：拖延行为（691 条相关效应的元分析汇总）。
- **主要结论**：任务厌恶、任务延迟、自我效能与冲动性是最强且最一致的拖延预测因素；神经质/叛逆/感觉寻求与拖延只有弱关联；尽心性负向预测拖延。结果支持 TMT。
- **证据强度**：高。大型元分析（691 个相关系数），Psychological Bulletin（顶刊），被引 3300+。
- **研究局限**：多数原始研究为横断面自我报告；因果关系推断有限。
- **与本项目的关系**：直接为 User State 的"拖延风险估计"提供核心变量集。
- **支持的系统设计**：Duration Predictor 中加入"任务厌恶值"与"自我效能"修正项；Scheduler 依据 deadline 距离做双曲贴现式提醒强度/分段时间调整。
- **可采集数据**：task logs（任务类型、价值/厌恶评分、距 deadline 天数）、用户自评 self-efficacy 量表、历史完成率。
- **可形成的 User State**：`procrastination_risk`（由 task aversiveness、self-efficacy、impulsivity、deadline 距离合成）。
- **可成为哪一部分**：Rule/Statistical Model——拖延风险评分公式（TMT 模型的权重拟合）；也是 Replanning Trigger 的输入。
- **推荐优先级**：★ 最高。TMT 是整条证据链的骨架理论。

### 2. Solomon & Rothblum (1984) — 学业拖延的频率与认知行为相关因素

- **研究问题**：学生拖延的频率如何？拖延的原因结构如何（因素分析）？
- **核心理论**：拖延的认知-行为视角（恐惧失败 vs 任务厌恶两因素结构）。
- **IV**：任务类型（论文、考试、每周阅读等 6 类）、原因维度。
- **DV**：拖延频率（学业拖延评估量表 PASS 是其产物）。
- **主要结论**：约半数学生报告频繁拖延；拖延原因可归为"恐惧失败"与"任务厌恶"两大因素。
- **证据强度**：中。经典横断面问卷研究（N=342），被引 1600+，开创 PASS 量表。
- **研究局限**：自我报告、样本单一（美国大学生）。
- **与本项目的关系**：PASS 的"原因维度"可作为任务级特征提取的启发（区分"怕失败型"与"厌恶型"拖延）。
- **支持的系统设计**：规则引擎可在计划生成时为高风险任务附加"恐惧失败/厌恶"标签，指导任务拆分粒度。
- **可采集数据**：任务分类、用户对任务的情绪评分。
- **可形成的 User State**：`procrastination_profile`（怕失败 vs 厌恶型）。
- **可成为哪一部分**：LLM Harness 的 prompt 素材（生成鼓励/拆解文案时区分两类动机）；Rule 中的任务类型触发。
- **推荐优先级**：★ 高。奠定任务类型与拖延类型的映射。

### 3. Senécal et al. (1995) — 自我调节与学业拖延

- **研究问题**：自主性自我调节是否能预测学业拖延？
- **核心理论**：自我决定理论（内在动机 vs 外在调节 vs 去动机）。
- **IV**：学业动机自治程度、抑郁、自尊、焦虑。
- **DV**：学业拖延水平（回归：调节变量解释 25% 方差 > 情绪变量 14%）。
- **主要结论**：自主调节（内在原因）更强的人拖延更少；拖延本质上是动机问题而非时间管理或懒惰。
- **证据强度**：中。横断面回归（N=498 法语大龄学生），被引 568。
- **研究局限**：横断面自报告，无法定因果。
- **与本项目的关系**：提醒我们"为什么做"（动机类型）比"会不会安排时间"更能解释拖延。
- **支持的系统设计**：LLM Harness 做任务价值叙事（将任务与用户内在目标关联）以降低拖延。
- **可采集数据**：目标-任务关联度自评、自主动机量表。
- **可形成的 User State**：`autonomous_motivation`。
- **可成为哪一部分**：ML 特征；LLM Harness 的价值重塑话术。
- **推荐优先级**：★ 高。

### 4. Haycock et al. (1998) — 自我效能、焦虑与拖延

- **研究问题**：效能期望与焦虑对重大任务拖延的相对预测力。
- **核心理论**：自我效能理论（Bandura）。
- **IV**：对完成项目所需技能的效能期望、焦虑、性别、年龄。
- **DV**：拖延程度。
- **主要结论**：双变量相关中效能与焦虑均与拖延显著相关；回归中只有效能强度是拖延的显著预测因子（N=141）。
- **证据强度**：中。横断面回归，被引 362。
- **研究局限**：样本小、单一项目设定。
- **与本项目的关系**：支持"自我效能直接进拖延预测模型"。
- **支持的系统设计**：任务申请（task planning）时询问用户对目标的效能评分（1-7），作为 Duration Predictor/拖延修正的输入。
- **可采集数据**：任务级 self-efficacy 评分。
- **可形成的 User State**：`task_self_efficacy`。
- **可成为哪一部分**：Statistical Model 的回归特征；Rule 的阈值触发（效能低→强制拆子任务）。
- **推荐优先级**：★ 高。

### 5. Klassen et al. (2007) — 自我调节自我效能低预测更高拖延

- **研究问题**：哪种自我效能（一般学业自我效能 vs 自我调节自我效能）更能预测拖延？
- **核心理论**：自我效能理论、自我调节学习。
- **IV**：学业自我效能、自我调节自我效能。
- **DV**：学业拖延（本科与教师教育样本）。
- **主要结论**：自我调节自我效能是拖延最强的预测因子（"我能让自己坐下来学吗"强于"我能学好这门课吗"）。
- **证据强度**：中-高。两样本横断面，被引 679。
- **研究局限**：横断面自报告。
- **与本项目的关系**：区分"能力信心"与"启动/坚持信心"，后者对推迟开始更关键——对应系统 onset delay 预测。
- **支持的系统设计**：对"启动困难"用户采用实施意图式提醒（implementation intention），而非仅信息性提醒。
- **可采集数据**：启动信心评分、任务启动前的行为准备日志。
- **可形成的 User State**：`initiation_self_efficacy`。
- **可成为哪一部分**：ML 特征；Replanning Trigger（启动多次失败且效能低时触发计划重排）。
- **推荐优先级**：★ 高。

### 6. Steel & Klingsieck (2016) — 学业拖延心理前因再审视

- **研究问题**：除尽责性之外的四大性格如何影响拖延的表现形式？
- **核心理论**：大五人格 + 需求理论。
- **IV**：大五人格（尽责性为核心）、拖延时从事的活动、归因理由。
- **DV**：拖延程度及现象学（拖延时的行为）。
- **主要结论**：尽责性及其子维度是与拖延最强的相关变量；其他性格不增量预测拖延，但决定拖延的"表现形式"（神经质型 vs 厌恶型等）。
- **证据强度**：中。单一本科课程样本（N=167），但为综述框架文，被引 527。
- **研究局限**：样本单一人群。
- **与本项目的关系**：提示 User State 应以"尽责性/自控"为主轴，其他特征用于干预风格定制。
- **支持的系统设计**：用户画像中记录尽责性（简版量表或行为代理），据此选择干预话术（高压型 vs 温和型）。
- **可采集数据**：behavioral proxies of conscientiousness（准时性、计划遵循率）。
- **可形成的 User State**：`trait_conscientiousness`。
- **可成为哪一部分**：LLM Harness 个性化 prompt；User State 长期档案。
- **推荐优先级**：★★ 中高。人格类稳定状态，适合低频更新。

### 7. van Eerde (2003) — 拖延的元分析命名网络

- **研究问题**：拖延与其前因/后果变量的总体相关矩阵。
- **核心理论**：拖延作为自我调节失败（以前瞻性视角综合）。
- **IV/DV**：拖延与动机、情绪、人格、绩效等的关系（元分析 k 与效应量）。
- **主要结论**：拖延与责任心、行动导向负相关显著，与干扰因素正相关；为后续模型提供统一的效应量底表。
- **证据强度**：高。元分析（Personality and Individual Differences），被引 625。
- **研究局限**：原始研究多为自报告。
- **与本项目的关系**：提供效应量底表用于权重初始化。
- **支持的系统设计**：拖延风险回归的效应量先验。
- **可采集数据/User State**：同 [1]；为模型参数提供先验。
- **可成为哪一部分**：Statistical Model 初始化。
- **推荐优先级**：★ 高（模型权重来源）。

### 8. Kim & Seo (2015) — 拖延与学业表现的元分析

- **研究问题**：拖延与学业成绩关系的总体效应量与调节因素。
- **核心理论**：拖延损害学习投入的认知-动机通路。
- **IV**：拖延测量类型（量表种类）、研究方法、时间跨度。
- **DV**：学业成绩（GPA、课程分等）。
- **主要结论**：拖延与学业表现呈中等负相关（负效应稳定）。
- **证据强度**：高。元分析（2015），被引 788。
- **研究局限**：多数研究横断面。
- **与本项目的关系**：为"完成度/成绩预测"模型中拖延特征提供依据。
- **支持的系统设计**：Duration Predictor 中含拖延修正项后，计划完成率估计更准。
- **可采集数据**：作业/任务完成分数。
- **可形成的 User State**：`academic_performance_state`。
- **可成为哪一部分**：Statistical Model；评估模块的基准。
- **推荐优先级**：★ 高。

### 9. Akpur (2020) — 拖延对学业成就的元分析（Effect size）

- **研究问题**：拖延→学业成就的总体效应大小。
- **核心理论**：拖延对结果变量的负性路径。
- **IV**：拖延水平；**DV**：学业成就。
- **主要结论**：总体负相关（报告总体效应量约 -0.61，中等效应），22 项研究 8307 人。
- **证据强度**：中。元分析但入组标准/数据库较窄（ERIC + Academic Search Ultimate）。
- **研究局限**：原始研究同质性问题。
- **与本项目的关系**：量化拖延对目标的损害量级，供规则阈值设计（如"拖延高→自动拆分计划"）。
- **支持的系统设计**：Replanning Trigger 的增益评估。
- **推荐优先级**：★★ 中。

### 10. Kooren et al. (2024) — 主动型与被动型拖延对学业的元分析

- **研究问题**：主动拖延（act passive）是否与被动拖延对学业表现有不同的影响？
- **核心理论**：主动拖延（时间压力下蓄意工作）与被动拖延的区分。
- **IV**：拖延类型（主动/被动）、样本特征。**DV**：学业表现。
- **主要结论**：总体拖延与学业成绩呈弱负相关；主动拖延呈小正效应，被动拖延呈小负效应（96 项研究、176 个系数、约 5.5 万人）。
- **证据强度**：中-高。最新大型元分析。
- **研究局限**：主动/被动分类依赖自报量表。
- **与本项目的关系**：Scheduler 不应无差别消除所有"拖"——保留用户偏好压力型工作的自由度；User State 区分 active/passive 拖延者。
- **支持的系统设计**：Scheduler 可按用户类型决定是否在 deadline 前分散排程（被动型需要更分散，主动型可接受紧凑）。
- **可采集数据**：deliberate deferral 的自报（是否蓄意拖延）。
- **可形成的 User State**：`procrastination_style`（active/passive）。
- **可成为哪一部分**：User State 聚类；ML 分类特征。
- **推荐优先级**：★ 高（影响调度策略分流）。

- **推荐优先级**：★★ 中高。

## 四、方向小结（对 DAMN 项目的关键含义）

1. **拖延可预测且可参数化**：历史拖延（意图-行动差距、实际完成延迟）能稳定预测未来拖延（[12][16][23]）；个体双曲线贴现参数可从 task logs 拟合，进入 Scheduler/Duration Predictor。
2. **预测因子主次分明**：任务厌恶、自我效能（尤其自我调节自我效能）、冲动/自控、deadline 距离是主预测因子；神经质、难度感知、恐惧并非稳定预测源（[1][5][20]）。
3. **Deadline 设计有陷阱**：中等长度单一时限表现最差（[14]），slippery deadline 会放大拖延（[16]），预期性提醒可能助长拖延（[17]）；多段紧时限 + 非预期提醒 + 随机检查点是更稳策略。
4. **动态 vs 稳定状态分离**：onset 延迟与 sustained 延迟是不同构念（[18]）；主动拖延者不应被打压（[10][21]）；拖延处于自我效能反馈回路中（[23]），系统应主动打破恶性循环。
5. **干预设计优先级**：CBT/动机性/情绪调节取向优于纯时间管理训练（[11][22]）；检测"合理化借口"并拆解任务情绪负担是 LLM Harness 的落点（[15][19][22]）。
