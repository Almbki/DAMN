# 需求共识 · 速览

> 详版：`docs/需求共识.md`（自包含，含完整论证与源文件指针）｜ 2026-09-20 · 待团队评审

## 一句话

一个**反馈驱动的自适应任务规划器**：把模糊目标拆成一步可完成的任务，并让计划**随人的状态自动调整**。

- **双主张**：① **个人定制的日程排期**（"不用自己想今天该做什么"）② **状态自适应**（"计划不会因状态崩了就作废"）
- **次要**：估时准 / 知识不遗忘（暂缓）
- **自适应优先级**：用户状态 > 完成率 > 执行偏差 > 遗忘
- **交付判据**：自己 / 小范围能真实用起来（不设量化指标）
- **形态**：只交付后端；按生产标准设计、规模小；前端由他人开发

# 关键决策速查

| 主题 | 决策 |
|---|---|
| 目标分解 | 目标 → 任务 **两层**，不建子目标表 |
| 计划 | **时间窗**（可含多目标）；版本不可变；**事件驱动**产生新版本 |
| 局部修复 | 只改**未来 2 天**；30% 是 `full_replan` 的档门 |
| 拆解流程 | 添加 → 自动进入 → **草案预览** → 编辑时可 **AI 澄清（diff 确认）** → 确认；取消存**草稿** |
| 目标进度 | 按**预估时长加权** |
| 用户权限 | 草案随便改；已落库计划**只能改状态/执行数据，不能改排期** |
| 重规划 | **全自动**（完成率 <0.5，per-user 48h 冷却）+ 可解释 + 可撤销 |
| 反馈采集 | **整体采用 RO-3**：注册 12–15 题；每日 3+1；任务后 1–2；≤5 题/天 + 熔断 |
| 失败归因 | **预选式**；六选项：太难/没时间/不想做/被打断/忘了/其他 |
| 被动信号 | 后端可算的 **8 项**；前端 4 项；**打字动力学砍掉** |
| 标签 | **全自由标签** |
| 洞察面板 | 不是报表，是**闭环** |
| 画像页 | 现状 + 趋势 + 充足度 + 依据；禁止人格评价词 |
| 提醒 | 后端出**决策**、前端**投递** |
| 设置 | 账号 + **排程偏好持久化** |
| 首次使用 | 填档案 → 建目标 → 出第一份计划 |
| 规则 R1 | **不做成规则**，改 Scheduler 默认行为（证据 mixed，见详版附录 A） |
