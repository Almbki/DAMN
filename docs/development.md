# Development Guide

## 1. Prerequisites

- Python **3.12+** (the project pins `requires-python = ">=3.12"`)
- [uv](https://docs.astral.sh/uv/) — install with
  `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"` (Windows) or
  `curl -LsSf https://astral.sh/uv/install.sh | sh` (Unix)
- Docker (optional, for PostgreSQL)
- `uv` can manage the interpreter: `uv python install 3.12`

## 2. Install

```bash
uv sync --extra dev        # creates .venv and installs runtime + dev deps
```

> **README.md must exist.** `pyproject.toml` declares `readme = "README.md"`;
> the hatchling build fails with `OSError: Readme file does not exist` if it is
> missing.

## 3. Configure

```bash
cp .env.example .env          # Windows: Copy-Item .env.example .env
```

Key variables (full list in `.env.example`):

| Variable | Default | Notes |
| --- | --- | --- |
| `DATABASE_URL` | `sqlite:///./dev.db` | or `postgresql+psycopg://planner:planner@localhost:5432/planner` |
| `DB_ECHO` | `false` | SQL echo |
| `JWT_SECRET_KEY` | `change-me-in-production` | **≥ 32 bytes** for HS256 |
| `JWT_ALGORITHM` | `HS256` | |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `10080` | 7 days |
| `LLM_PROVIDER` | `mock` | `mock` or `openai_compatible`-style HTTP |
| `LLM_API_BASE` / `LLM_API_KEY` / `LLM_MODEL` | — | used when provider != mock |
| `SCHEDULER_DAILY_LIMIT_MINUTES` | `300` | default daily cap |
| `SCHEDULER_BUFFER_MINUTES` | `15` | min gap between tasks |
| `SCHEDULER_HIGH_COGNITIVE_MAX_PER_DAY` | `2` | high-cognitive cap |
| `SCHEDULER_MIN_REPLAN_INTERVAL_HOURS` | `24` | replan cooldown |
| `GENERATION_JOB_TTL_SECONDS` | `1800` | in-memory job retention |

Generate a production secret:

```bash
uv run python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## 4. Database

### SQLite (default, zero setup)

`DATABASE_URL=sqlite:///./dev.db`. On startup the app calls `init_db()`
(`create_all`) when the URL is SQLite, so you can run immediately.

### PostgreSQL

```bash
docker compose up -d db        # start just Postgres
# .env: DATABASE_URL=postgresql+psycopg://planner:planner@localhost:5432/planner
uv run alembic upgrade head
```

## 5. Alembic migrations

```bash
uv run alembic current                                   # applied revision
uv run alembic upgrade head                              # apply all
uv run alembic revision --autogenerate -m "add x"        # after model changes
uv run alembic downgrade -1                              # roll back one
```

`alembic/env.py` reads `DATABASE_URL` from `Settings` (no URL in `alembic.ini`),
imports `app.infrastructure.database.models` so metadata is complete, and uses
`render_as_batch=True` for SQLite. The initial migration is
`alembic/versions/4e95b02e3696_initial_schema.py`.

> Always review autogenerated migrations — SQLite batch mode can rewrite tables.

## 6. Run the API

```bash
uv run uvicorn app.main:app --reload
# or
uv run python -m app.main            # uses app.main.run() (no reload control)
```

- Swagger UI: <http://localhost:8000/docs>
- ReDoc: <http://localhost:8000/redoc>
- OpenAPI JSON: <http://localhost:8000/openapi.json>
- Health: <http://localhost:8000/health>

## 7. Tests

```bash
uv run pytest                       # all
uv run pytest tests/unit -q         # domain / security / ml
uv run pytest tests/api -q          # endpoint contracts
uv run pytest tests/integration -q  # full feedback loop
uv run pytest -k scheduler -v
```

`tests/conftest.py` sets `DATABASE_URL=sqlite:///./test_damn.db` and
`JWT_SECRET_KEY=test-secret-key` **before** importing the app, creates the schema
once per session, and provides `client`, `registered_user` and `auth_headers`
fixtures.

## 8. Lint

```bash
uv run ruff check .
uv run ruff format .
```

## 9. Docker

```bash
docker compose up --build       # Postgres + API on :8000
docker compose down -v          # stop and remove volumes
```

The API container runs `uvicorn app.main:app --host 0.0.0.0 --port 8000` against
the `db` service.

## 10. Troubleshooting

| Symptom | Cause / fix |
| --- | --- |
| `OSError: Readme file does not exist: README.md` during `uv sync` | `README.md` missing; it is declared in `pyproject.toml` |
| `sqlite3.ProgrammingError: SQLite objects created in a thread…` | handled: the engine passes `check_same_thread=False` for SQLite |
| `InsecureKeyLengthWarning: The HMAC key is … below 32 bytes` | `JWT_SECRET_KEY` too short — generate one with `secrets.token_urlsafe(48)` |
| `alembic.util.exc.CommandError: Can't locate revision` | delete `dev.db` and `alembic upgrade head` again |
| `ModuleNotFoundError: app` | run from the repo root or use `uv run` (sets `pythonpath`) |
| `/docs` returns 404 | app built without `docs_url`; ensure you run `app.main:app` |
| LangGraph not installed | `app/agent/graph.py` falls back to a sequential executor; install `langgraph` for the real graph |
| Replan returns `409 replan_not_eligible` | user-level cooldown (`SCHEDULER_MIN_REPLAN_INTERVAL_HOURS`) is active |

## 11. Conventions

- Layers: API → Application → Domain/Core → Infrastructure; never violate the
  import direction.
- Type hints everywhere; `from __future__ import annotations`.
- Services are synchronous and own transactions; repositories only `flush`.
- New hard constraints go in `app/domain/rules/` and must be registered in
  `default_rules()`.
- Mark any mock/placeholder explicitly in docstrings.
